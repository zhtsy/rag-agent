# 知识库检索技能

## 概述
本技能用于从本地知识库中检索与用户问题相关的信息。

## 指令
1.  当用户的问题涉及人物信息或知识库内容时，调用 `search_knowledge_base` 工具。
2.  将用户的完整问题作为 `query` 参数传递给该工具。
3.  根据工具返回的结果来回答用户。

## 示例
- 用户问：“小智喜欢什么？”
- 你的操作：调用 `search_knowledge_base` 工具，参数 `query="小智喜欢什么？"`。
- 工具返回相关文档后，基于文档内容生成回答。
